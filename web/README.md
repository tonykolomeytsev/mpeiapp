# MpeiX Next Web (PWA)

Веб-версия расписания для iPhone и любых браузеров. Устанавливается через Safari
(«Поделиться» → «На экран „Домой“»), App Store не нужен. Код Android-приложения не затрагивается.

## Возможности
- поиск группы или преподавателя, расписание по неделям и дням, номер недели семестра;
- тёмная и светлая тема (по настройкам системы), подсветка идущей пары;
- оффлайн: оболочка приложения и последние загруженные недели;
- push-уведомления об изменениях расписания (iOS 16.4+, только из установленного на экран «Домой» приложения).

## Как это устроено
```
public/    статика: index.html, app.js, styles.css, sw.js, manifest, иконки
           schedule.js — общая логика (маппер ts.mpei.ru и детектор изменений, порт из Kotlin)
worker/    Cloudflare Worker: прокси /api/* к ts.mpei.ru (у API нет CORS),
           /push/* (подписки), cron раз в 30 минут (проверка изменений и push)
test/      node:test — логика расписания и воркер (cron, VAPID-подпись, очистка подписок)
```
Push отправляется без тела (VAPID), текст сообщения service worker забирает через `/push/pending`.

## Запуск локально
```bash
cd web
npm install
npm test
npm run dev        # http://localhost:8787
```

## Деплой (бесплатный план Cloudflare)
1. Аккаунт на https://dash.cloudflare.com (карта не нужна), затем `npx wrangler login`.
2. Хранилище подписок: `npx wrangler kv namespace create SUBS` — вставьте полученный `id` в `wrangler.toml`.
3. Ключи для push: `npm run vapid`
   - публичный ключ запишите в `wrangler.toml` → `VAPID_PUBLIC_KEY`, укажите свой `VAPID_SUBJECT` (mailto:);
   - приватный: `npx wrangler secret put VAPID_PRIVATE_JWK` и вставьте строку JSON.
4. `npm run deploy` — получите адрес вида `https://mpei-next-web.<ваш-поддомен>.workers.dev`.
5. На iPhone откройте адрес в **Safari**, «Поделиться» → «На экран „Домой“», запустите с главного экрана,
   выберите группу, в настройках включите уведомления.

## Ограничения
- Бесплатный план Workers даёт 50 внешних запросов на один запуск cron. Воркер обрабатывает
  расписания по кругу (3 запроса на расписание + по одному push на подписчика), поэтому при сотнях
  уникальных групп проверка отдельной группы может происходить реже, чем раз в 30 минут.
- iOS показывает push только установленному на экран «Домой» PWA и только после разрешения по нажатию.
- Данные берутся с ts.mpei.ru; при недоступности сервиса показываются сохранённые недели.
