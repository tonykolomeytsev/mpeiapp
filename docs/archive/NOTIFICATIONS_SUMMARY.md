## 🚀 БЫСТРЫЙ СТАРТ (30 минут)

### 1. Добавить зависимости

```gradle
// modules/feature/schedule/impl/build.gradle
implementation("androidx.work:work-runtime-ktx:2.9.0")
implementation("org.jetbrains.kotlinx:kotlinx-serialization-json:1.6.2")
```

### 2. Скопировать файлы

Все 6 `.kt` файлов уже созданы в:
```
modules/feature/schedule/impl/src/main/kotlin/kekmech/ru/feature_schedule_impl/notifications/
```

### 3. Добавить в Koin DI

```kotlin
val scheduleNotificationsModule = module {
    single { ScheduleNotificationManager(androidContext()) }
    single { ScheduleCacheManager(androidContext(), get()) }
    single { ScheduleChangeScheduler(androidContext()) }
    
    single {
        Json {
            ignoreUnknownKeys = true
            prettyPrint = false
        }
    }
}
```

### 4. Запустить в Application

```kotlin
class MpeixApplication : Application(), KoinComponent {
    private val scheduler: ScheduleChangeScheduler by inject()
    
    override fun onCreate() {
        super.onCreate()
        // Запустить проверку каждые 6 часов
        scheduler.startPeriodicChecks(intervalHours = 6)
    }
}
```

### 5. Готово! 🎉

Система будет проверять расписание каждые 6 часов и отправлять уведомления об изменениях.

---

## 💡 КАК ЭТО РАБОТАЕТ

```
Каждые 6 часов:
    ↓
WorkManager запускает ScheduleChangeWorker
    ↓
Worker загружает свежее расписание с API
    ↓
Сравнивает со старым (из кеша)
    ↓
Если есть изменения → отправляет уведомление
    ↓
Обновляет кеш
```

### Пример уведомления:

```

          [Tap = Открыть расписание]
```

## 🎯 ТИПЫ ИЗМЕНЕНИЙ

Система обнаруживает 4 типа изменений:

1. **ADDED** (➕) - Добавлена новая пара
2. **REMOVED** (❌) - Пара отменена
3. **MODIFIED** (✏️) - Изменились детали (время, аудитория, преподаватель)
4. **REPLACED** (🔄) - Пара заменена на другую
