# 🎨 НОВЫЕ АНИМАЦИИ ЗАПУСКА ДЛЯ MPEI APP

## 📦 Созданные варианты

### 1. ⚛️ Энергетический реактор (`animated_splash_logo_energy.xml`)
**Концепция:** Атомное ядро с вращающимися электронами

**Особенности:**
- 🔴 Пульсирующее оранжевое ядро (реактор)
- 🔵 Три орбиты с электронами (циан, синий, фиолетовый)
- ✨ Энергетические частицы по углам
- 📝 Надпись "MPEI" снизу с fade-in эффектом

**Анимация:**
- Ядро пульсирует (scale 1.0 → 1.15)
- Орбиты вращаются с разной скоростью:
  - Внутренняя: 2 сек (по часовой)
  - Средняя: 3 сек (против часовой)
  - Внешняя: 4 сек (по часовой)
- Частицы пульсируют и вращаются

**Цветовая схема:**
- Фон: Темно-синий (#0D2A5C)
- Ядро: Оранжевый (#FF6B35) + Желтый (#FFAD5A)
- Орбиты: Голубой (#00E5FF), Синий (#448AFF), Фиолетовый (#7C4DFF)

---

### 2. ⚡ Электрическая молния (`animated_splash_logo_lightning.xml`)
**Концепция:** Энергетическая молния с волнами

**Особенности:**
- ⚡ Стилизованная золотая молния по центру
- 🌊 Три волны энергии, расходящиеся от центра
- ✨ Плавающие энергетические частицы
- 🔲 Технологичная сетка на фоне

**Анимация:**
- Молния мигает (flash эффект)
- Волны расширяются от центра с задержкой
- Частицы плавно поднимаются и опускаются
- Текст появляется с fade-in

**Цветовая схема:**
- Фон: Темно-синий (#0A1929)
- Молния: Золотой (#FFD700) + Желтый (#FFEB3B)
- Волны: Циан (#00E5FF)
- Сетка: Белый с прозрачностью

---

### 3. 🔄 Энергетическая турбина (`animated_splash_logo_turbine.xml`)
**Концепция:** Вращающаяся турбина генератора

**Особенности:**
- 🔄 8 лопастей турбины
- 🔴 Пульсирующее ядро генератора
- 💚 Индикаторы питания по углам
- 🌀 Магнитные силовые линии
- ⚡ Символ питания в тексте

**Анимация:**
- Лопасти вращаются плавно (2.5 сек)
- Ядро пульсирует (генерация энергии)
- Силовые линии вращаются
- Индикаторы мигают по очереди

**Цветовая схема:**
- Фон: Темно-синий (#001F3F)
- Турбина: Голубой (#00D9FF) + Синий (#0099CC)
- Ядро: Оранжевый (#FF6B35)
- Индикаторы: Зеленый (#00FF00)

## 🔧 Как применить новую анимацию

### Вариант 1: Заменить текущую анимацию

1. **Выберите понравившуюся анимацию:**
   - `animated_splash_logo_energy.xml` - атомный реактор
   - `animated_splash_logo_lightning.xml` - молния
   - `animated_splash_logo_turbine.xml` - турбина

2. **Замените файл:**
   ```bash
   # Сделайте backup текущей анимации
   cp modules/app/src/main/res/drawable/animated_splash_logo.xml modules/app/src/main/res/drawable/animated_splash_logo_old.xml
   
   # Замените на новую (например, turbine)
   cp modules/app/src/main/res/drawable/animated_splash_logo_turbine.xml modules/app/src/main/res/drawable/animated_splash_logo.xml
   ```

3. **Пересоберите проект:**
   - В Android Studio: **Build → Rebuild Project**
   - Или: `./gradlew clean assembleDebug`

### Вариант 2: Добавить выбор в настройках

Можно добавить настройку, позволяющую пользователю выбирать анимацию запуска.

**Для этого нужно:**
1. Сохранить все три варианта в `res/drawable/`
2. Добавить настройку в `SettingsScreen`
3. Применять выбранную анимацию динамически

## 🎯 Дополнительные идеи

### Если хотите настроить анимацию:

**Изменить скорость:**
```xml
<!-- Найдите android:duration и измените значение -->
<objectAnimator
    android:duration="2500"  <!-- Больше = медленнее -->
```

**Изменить цвета:**
```xml
<!-- Найдите android:fillColor или android:strokeColor -->
<path
    android:fillColor="#FF6B35"  <!-- Замените на свой цвет -->
```

**Добавить свой текст:**
