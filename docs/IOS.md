# iOS-версия: сборка и установка на iPhone

iOS-версия делается на Kotlin Multiplatform + Compose Multiplatform из кода этого репозитория; план и статус по этапам —
в issue [#5](https://github.com/ghostoftheeleven/mpei-next/issues/5). Mac не нужен: приложение собирает GitHub Actions
на macOS-раннере, готовый файл ставится на телефон с Windows.

> Что внутри сборки, зависит от этапа плана в #5. На этапе M0 в приложении только заглушка, которая проверяет сам конвейер;
> настоящие экраны переносятся по модулям.

## Как получить `.ipa`

1. Репозиторий → **Actions** → workflow **iOS** → нужный запуск (зелёный) → блок **Artifacts** внизу страницы.
2. Скачать **`ios-ipa-unsigned`** (скачивание требует входа в GitHub). Внутри zip — файл `MPEI-Hub-ios-unsigned.ipa`.
3. Новый запуск: Actions → iOS → **Run workflow**. Сборка идёт ~15–30 минут (первая дольше: скачивается компилятор Kotlin/Native).

`.ipa` **не подписан**: iPhone его не установит напрямую, он подписывается на ПК вашим Apple ID (шаг ниже).

## Установка на живой iPhone с Windows (бесплатно, Sideloadly)

Подготовка (один раз):

1. Завести **отдельный Apple ID** для разработки (не основной).
2. Установить **iTunes** и **iCloud** с сайта Apple — не из Microsoft Store.
3. Установить **Sideloadly** (sideloadly.io).
4. На iPhone с iOS 16 и новее включить **Режим разработчика**: Настройки → Конфиденциальность и безопасность → Режим разработчика (потребуется перезагрузка).

Установка:

1. Подключить iPhone кабелем, на телефоне нажать «Доверять этому компьютеру», в iTunes убедиться, что телефон виден.
2. В Sideloadly перетащить `MPEI-Hub-ios-unsigned.ipa`, выбрать устройство, ввести Apple ID, нажать **Start**.
3. На iPhone: Настройки → Основные → VPN и управление устройством → профиль разработчика → **Доверять**.
4. Запустить «МЭИ.Хаб».

Ограничения бесплатного Apple ID: подпись действует **7 дней** (затем приложение нужно переустановить или обновить через Sideloadly),
не больше **3** активных приложений, виджеты и App Groups работают ограниченно. Платный Apple Developer Program ($99 в год)
снимает ограничения и нужен для TestFlight и App Store; из России его оформление по сообщениям пользователей проблематично.

## Для разработчиков

- Модуль `modules/shared` (KMP) собирается в статический фреймворк `Shared`; оболочка `iosApp` (SwiftUI) показывает его Compose-UI.
- Xcode-проект не хранится в git: он генерируется [XcodeGen](https://github.com/yonaskolb/XcodeGen) из `iosApp/project.yml`:
  `cd iosApp && xcodegen generate`, затем открыть `iosApp.xcodeproj` на Mac. Сборка фреймворка встроена в Xcode через Gradle-задачу
  `:shared:embedAndSignAppleFrameworkForXcode`.
- Идентификатор приложения — `ru.mpei.hub`, минимальная iOS — 15.
- Локально на Windows iOS-часть не компилируется (нет Xcode); проверка идёт только в CI. Android-сборка от модуля `:shared` не зависит.
